# Interactive Birthday Celebration Web Template

A customizable, responsive birthday celebration web page featuring an interactive quiz logic, typewriter effects, and a photo showcase gallery.

---

## ✨ Features
* **Interactive Quiz Logic:** Engagement features that require users to answer fun questions before unlocking the main content.
* **Photo Showcase:** A beautifully arranged gallery for displaying memorable moments (default placeholders provided).
* **Smooth Animations:** Built with modern CSS/JS for an immersive user experience.
* **Modern Tech Stack:** Fast build and hot-reloading powered by Vite.

---

## 🛠️ Tech Stack
* **Frontend Framework:** React
* **Build Tool:** Vite
* **Deployment:** Vercel

---

## 📦 How to Run Locally

If you want to clone this repository and run it on your machine, follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com/Carie001/birthday-page-template.git
```

### 2. Install dependencies
Make sure you have Node.js installed, then run:
```Bash
npm install
```

### 3. Run the development server
Start the local server to preview the website:
```Bash
npm run dev
```
Once started, open your browser and go to http://localhost:5173 (or the port specified in your terminal).

### 4. Build for production
To create a production-ready build:
```Bash
npm run build
```
